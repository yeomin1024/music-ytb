멜로디 찍기

4/4박자 한 마디(16칸)에 멜로디를 찍고, 아래 멜로디 코드를 복사해 Kaggle 반주 패널의 '멜로디 코드' 칸에 붙여 넣으세요. 칸을 클릭하거나, 건반을 차례로 누르거나, 허밍 녹음 파일을 올리면 됩니다.

빈 칸 클릭 = 음 찍기 (옆으로 끌면 그만큼 길게) · 음 클릭 = 지우기 · 음을 잡고 옆으로 끌기 = 길이 바꾸기 · 왼쪽 건반 = 소리 듣기 · 맨 위 박자 줄 클릭 = 커서(차례로 찍기 시작 자리). 파란 점 줄 = 으뜸음, 흐린 줄 = 음계 밖 음.

건반으로 차례로 찍기

위에서 고른 음 길이로, 커서 자리부터 하나씩 채워집니다.

허밍으로

휴대폰 녹음 앱으로 '라라라'나 '음~'으로 또박또박 불러 녹음한 파일(m4a·mp3·wav)을 올리면 음을 찾아 칸에 채웁니다. 앞뒤 조용한 부분은 잘라냅니다. 이 페이지에서는 마이크를 바로 쓸 수 없어서 파일로 받습니다.
